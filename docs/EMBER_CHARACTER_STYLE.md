# Ember — канон персонажей (Dungeon Slasher)

Референс для ботов и пресетов редактора. Не движок, не пропы деревни.

Канонический кадр: [`refs/dungeon-slasher-character.png`](refs/dungeon-slasher-character.png)
(пиксель-арт в духе *Dungeon Slasher* roguelike).

## Силуэт

- Полу-чиби: большая голова (~¼ высоты), компактный торс, **длинные ноги**.
- Читается анфас, 45–60°, и сбоку. Не Minecraft-столбик и не супер-деформированный чиби 1:1.
- Толстый внешний контур (очень тёмный, не обязательно #000).
- Свет сверху-справа: тень на левой стороне волос и конечностей.
- Мало цветов: 3 тона волос, 2 кожи, 3 одежды, контур, глаза.

## Лицо и волосы

- Крупные глаза в 2 тона, блик. Носа и рта часто нет.
- Длинные объёмные волосы до середины бедра, чёлка, **ахоге**.
- Тонкая тёмная повязка / ободок.
- Уши чуть торчат из волос, не звериные (если не раса с ушками).

## Тело и костюм (стартовый пресет)

Это **язык формы**, не обязательный лор-наряд каждой героини:

- короткое пальто / топ: светлые плечи, тёмная грудь, светлее корсет;
- короткая юбка;
- тёмные перчатки / наручи до локтя, открытые пальцы если хватает пикселей;
- zettai ryouiki: полоска кожи между юбкой и чулками;
- тёмные чулки + простые сапоги.

## Воксели (`chibi_32` / `chibi_25d`, style `slasher`)

Тот же скелет и капсула 22 vx / макушка 32, что у чиби. Меняется заливка:

- волосы — масса, не 1-voxel пряди; близнецы = свисающие пряди, не тонкие палки;
- ахоге на слоте `ears` (не звериные уши);
- ободок на голове;
- торс слоями (плечи / грудь / корсет);
- ноги: кожа сверху, чулок, сапог.

Пресет в скульпторе: **+ Slasher** / **+ Slasher 2.5D**.

## Спрайты

Стартовый холст персонажа: **32×56**, один прямоугольник (без крышки/стены). Декор: **16×16**. Пустой: **32×48**.
Роли `player` + `npc`, теги `character`, `slasher`.
Пресет в редакторе спрайтов: **+ Slasher** (кнопка **S** в шапке ассетов).

Не раздувать холст до 64×64 «на всякий случай». Детали меньше 2 px не делать.

### План редактора спрайтов

1. Один холст — сделано.
2. Вёрстка шапки / ролей / палитры / тулбара — сделано.
3. Четыре вида на одном ассете (`front` / `back` / `side_l` / `side_r`), подмена при орбите камеры — сделано.
4. **Слои** (`artLayers[]` → композит в `pixels`) и кисти слоя — **сделано**:
   - **смягчение** — blur/soften по соседям, без смены hue;
   - **затемнение по тону** — burn: темнее, hue тот же;
   - **осветление по тону** — dodge: светлее, hue тот же;
   - **размазывание** — smudge: тянет цвет соседних пикселей.
   Glow/shine остаются материальными каналами, не арт-слоями.
5. Покадровая анимация (`frames[]` + `durationMs`) — **сделано**: optional `frames[]` (от 2 до 12), `durationMs` 40..2000 (по умолчанию 120). Корневые `pixels` / `views` / `artLayers` = кадр 0. Один кадр на диск не пишется. В play уникальные билборды крутят цикл; instanced batch — нет.

## Чего не делать боту

- Не копировать референс 1:1 как чужой персонаж с IP.
- Не мешать этот язык с `vox_vil_*` / толстыми проп-массами env-волн.
- Не ломать слоты скелета и не менять `src/**`, если задача — только ассет.
- Не ставить персонажа на карту в той же задаче, что генерация пресета.
