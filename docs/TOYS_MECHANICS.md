## Вибро-привод (`drive: "vibe"`)

Вместо метронома — профиль из `data/vibeProfiles.json`: сегменты `{ durationSec, level, labelRu }`.  
На экране — шкала `VibeHud`. Уровни 0–5 уходят в Device Bridge (Settings → Игрушка): mock / Lovense Game Mode / Buttplug·Intiface. На паузе и конце сессии — стоп.

Профили: мягкие волны · нарастание · пульс/удержание · тизер/отказ · плато у края.

| ID | Роль | Механика |
|----|------|----------|
| `chastity_cage` | worn | Блокирует обычную дрочку. Только комбо с vibe. |
| `lovense_edge2` | active | Простатный пульс под бит / фон. |
| `wand` | active | Внешний Hitachi-style. Головка, клетка, комбо. |
| `vibe_bullet` | active | Вибропуля — тот же слот `external` и группа `wand` / `external_vibe`. |
| `dildo_small` | worn | Thrust / plapping **или** worn-grind (группа `dildo` + `plug_static`). |
| `dildo_medium_vibe` | worn | Thrust + vibe **или** worn-grind с фоном. |
| `dildo_large` | worn | Глубокий thrust **или** тяжёлая worn-наполненность. |
| `vibrating_plug` | worn | Вибро-фон / основной стимул / комбо. |
| `plug` | worn | Пассивная наполненность (`plug_static`). |

Группа **`dildo`**: thrust / plapping / oral.  
Группа **`plug_static`**: пробка и все дилдо — ход `plug_passive` (grind) в дрочке, онахоле, CBT, клетке.

## Привязка игрушек к режимам

Принадлежность считается из `functions.json`: игрушка полезна в режиме, если есть
хотя бы одна функция с этим `requiresToys` (или `satisfies`), которая проходит
фильтр режима (см. `src/lib/toyModeAffinity.ts`).

Жёсткие правила старта — `src/lib/modeToyRules.ts` (План + рулетка):

| Режим | Минимум | Must-have слоты | «Без игрушек» |
|-------|---------|-----------------|---------------|
| Дрочка / Онахол / CBT | 0 | — | да |
| Анал | ≥1 | дилдо | нет |
| Орал | ≥1 | дилдо | нет |
| Клетка | ≥2 | клетка + партнёр (у Санны фокус: wand/пуля) | нет |
| Plapping (Санна) | ≥2 | клетка + дилдо | нет |
| Prone | 0 | — | принудительно |

**Санна:** клетка всегда. Дилдо **всегда готовим** на старте и используем по режиму (must в plapping/орал/анал). В клетке фокус очереди — wand/вибропуля; дилдо остаётся в loadout для grind/по ходу.

Оставшиеся слоты (до mood-max, поднятого до минимума) — из useful toys режима.

Рулетка: `toys_count` не предлагает ниже минимума; `toys_1…N` сначала крутят must-группы.
В Плане барабан скрывает «Без игрушек», если режим запрещает; смена режима чинит allow-list.

## Правила Conductor

1. В очередь попадают только функции, чьи `requiresToys` закрыты owned ∩ allowed.
2. В блок пишутся `modifiers[]` с конкретным toy id (для дилдо — выбранный размер).
3. Клетка-комбо несовместимы с обычным stroke руками (`incompatibleWith`).
4. На отдыхе игрушки можно оставить, без стимуляции.
5. Рулетка не выдаёт игрушку, если для выбранного режима нет подходящих функций.
